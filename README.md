# Stopwatch
This Stopwatch App allows users to track time with start, pause, reset, and lap features. It displays time in HH:MM:SS:MS format and saves lap times in a list. The design is clean, mobile-friendly, and built using vanilla JavaScript without any libraries. Created as part of my Prodigy InfoTech internship.
# ⏱️ Stopwatch App

A responsive digital stopwatch built with HTML, CSS, and JavaScript. Track time with start, pause, reset, and lap functionality with millisecond precision.

## ✨ Features

- **Start / Pause / Reset**: Full control over the timer
- **Lap Recording**: Save and view multiple lap times
- **Millisecond Accuracy**: Displays time in `HH:MM:SS:MS` format
- **Responsive UI**: Clean design that works on mobile, tablet, and desktop
- **No Dependencies**: Built with Vanilla JavaScript

## 🛠️ Tech Stack

- **HTML5** - Structure
- **CSS3** - Styling & Animations
- **JavaScript** - Timer Logic & DOM Manipulation
